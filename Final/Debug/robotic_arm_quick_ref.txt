Critical Paths (KEEP SHORT):
  1. ESP32 GND → PCA9685 GND → Servo GND (thick wire!)
  2. Servo VCC → [10000µF cap] → PCA9685 V+ (thick wire!)
  3. GPIO21 → PCA9685 SDA (use yellow wire)
  4. GPIO22 → PCA9685 SCL (use yellow wire)


COMPONENT SPECIFICATIONS
═════════════════════════

Servo Power Supply:
  • Voltage: 5-6V DC (NOT 3.3V!)
  • Current: Minimum 2A per servo (recommend 5A total)
  • Example: Mean Well RSP-75-5 (75W, 5V, 15A)
  • Or: Bench supply set to 5.5V, current limit 5A

Bulk Capacitor (servo supply):
  • Value: 10000µF (10mF) minimum
  • Voltage: 16V or higher
  • Type: Electrolytic (polarity matters! + to supply, - to GND)
  • Placement: As close as possible to servo power input

Bypass Capacitors (PCA9685):
  • Value: 100µF per device
  • Voltage: 16V+
  • Placement: Between VCC and GND on PCA9685

I²C Pull-up Resistors:
  • Value: 4.7kΩ (4700Ω)
  • Count: 2 (one on SDA, one on SCL)
  • Note: If PCA9685 board already has them, don't add more


TROUBLESHOOTING QUICK ANSWERS
═════════════════════════════════

Symptom                          Likely Cause
───────────────────────────────────────────────────────────────
Servo buzzes but doesn't move    Power supply voltage too low
                                 or common GND missing

"PCA9685 not found"              I²C wiring loose
                                 Wrong address (0x40 vs 0x41)
                                 SDA/SCL swapped

Some channels move, others don't Channels 8-15: Address issue
                                 Some channels: Solder joint
                                 
All arms move in test, but       Software (IK solver returns NaN)
gripper never moves              or firmware doesn't send to Ch5

Shoulder/wrist weak or glitchy   Supply voltage sags under load
                                 Add larger bulk capacitor
                                 Upgrade power supply
                                 OR add second supply for logic

Everything works but twitches     Jumper wires loose
randomly or locks up             Build perfboard PCB

ESP32 resets when servos move    Brown-out from current spike
                                 Add bulk cap + thicker power wires
                                 Reduce simultaneous servo motion

COMMON MISTAKES TO AVOID
═════════════════════════

❌ Powering servos from ESP32 USB
   ✓ Always use external 5-6V supply

❌ Forgetting common GND
   ✓ Must have: Servo GND ← → ESP32 GND

❌ No bulk capacitor
   ✓ Add 10000µF across servo supply input

❌ Noisy I²C (long jumper wires)
   ✓ Keep SDA/SCL short and twisted
   ✓ Build PCB for final version

❌ Testing with arm under load
   ✓ Run tests with arm supported or unloaded
   ✓ Load makes current spikes worse

❌ Ignoring brownout resets
   ✓ If ESP32 resets during servo motion
   ✓ → Upgrade power supply immediately
